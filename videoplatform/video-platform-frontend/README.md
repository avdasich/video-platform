# Video Platform frontend

React-интерфейс для учебной видеоплатформы. Здесь используются Create React App, React Router и Tailwind CSS.

Из этой папки выполни:

```bash
npm ci
npm start
```

Интерфейс откроется на http://localhost:3000. Для запросов к API нужен Django-сервер на http://localhost:8000. Локально запросы `/api/` проксируются на него через настройки `package.json`.

Общая инструкция по настройке проекта: [README в корне репозитория](../../README.md).
